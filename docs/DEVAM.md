## Teknik tasarım (benim kararlarım — KARARLAR.md'ye yazılacak)
**Havuz (requestTicket):** aktif sprintin, arşivsiz alanların `available/returned_to_pool` ticket'ları; tüm ön koşulları bitmiş (`PREREQ_DONE_STATUSES`); kişinin ana alanı **ve yönettiği alanlar** hariç; kişinin bu sprintte reddettikleri hariç. `ORDER BY random() LIMIT 1 FOR UPDATE OF t SKIP LOCKED`. Aynı kişinin çift tıklaması için `pg_advisory_xact_lock(hashtext('ticket-request:'||userId))`. Bekleyen teklifi varsa onu döndürür. Sonuç: `{kind:'offered'|'taken'|'empty', ...}`. Aktif sprint yoksa invalidState.
**acceptOffer:** status offered & assignee=aktör → taken, takenAt=now, dueAt=now+ticketHours, offeredAt=null. **rejectOffer:** hak>0 şart, `ticket_rejections` kaydı, → returned_to_pool, assignee null.
**Talepler (ek süre / geri çekme):** yalnız assignee, ticket `taken` iken (süre dolmuş olsa da), ticket başına tek bekleyen talep. Ticket → `extension_pending`/`withdrawal_pending`, `pausedAt=now`, `respondBy=now+managerResponseHours`. Konuşma: ticket kanalı (`channels.kind='ticket'`, tembel oluşturulur) + `messages.requestId`. Yönetici mesaj yazarsa `awaitingRequesterAt=now` (cevap süresi işlemez); talep sahibi cevaplayınca temizlenir, `respondBy` yeniden now+süre, `remindedAt/overdueAt` null. Cevaplayan ≠ talep sahibi; `canManageArea`.
- Ek süre onayı: `grantedHours` zorunlu; `dueAt += (now-pausedAt) + grantedHours`. Red / geri çekme reddi: `dueAt += (now-pausedAt)`, status taken. Geri çekme onayı: returned_to_pool, assignee/takenAt/dueAt/pausedAt/uyarı işaretleri null. Talep sahibi bekleyen talebini iptal edebilir (`cancelled`, geri sayım devam). Devamda `warnedAt`/`expiredNotifiedAt` artık geçerli değilse null'lanır (saf yardımcı: `src/lib/ticket-time.ts` — remaining = pausedAt ? dueAt-pausedAt : dueAt-now; resume).
**Teslim:** açıklama + 0-10 http(s) bağlantı + 0-5 dosya. assignee; status taken/extension_pending/withdrawal_pending (bekleyen talep `cancelled` olur, pausedAt null) ya da `submitted` (yeniden teslim, en sonuncusu geçerli). Süre dolduktan sonra da teslim edilebilir. Dosya: route handler `POST /api/dosya` (multipart, server action 1MB sınırına takılmasın diye), boyut `uploadMaxMb`, `UPLOAD_DIR/yyyy/mm/uuid`, `files` satırı sahipsiz; teslimde `submissionId` bağlanır (yalnız sahibinin bağlanmamış dosyaları). `GET /api/dosya/[id]` ticket'ı görebilene.
**Değerlendirme:** alan yöneticisi/ana yönetici, değerlendiren ≠ assignee; `submitted|evaluated` iken; değerlendirici başına tek kayıt (upsert), `submissionId` = son teslim; ticket → evaluated. Evaluated sonrası teslim yok.
**Ticket görme:** assignee + `canManageArea`. Üyeler havuzu göremez.
**Sprint sonu:** ana yönetici `active → closing` (o sprintteki `offered` ticket'lar havuza döner). Bitmemiş = sprintte `submitted/evaluated/cancelled` dışındakiler (taslaklar dahil). Alan yöneticisi (kendi alanları) ve ana yönetici ticket bazında karar verir, `sprint_end_decisions`'a yazılır, hemen uygulanır. Hedef sprint = aktif sprint (kapanan değilse) yoksa en küçük numaralı planlanmış; yoksa "önce sonraki sprinti planla" hatası. Handler kaydı (yeni seçenek eklenebilir), `sprint-end.ts` sözleşmesine `appliesTo` durumları + `needsNextSprint` eklenecek:
- move_next: tüm bitmemişler; sprintId=sonraki, durum aynen kalır.
- keep_assignee: taken/*_pending; sprintId=sonraki, dueAt=now+ticketHours (duraklıysa pausedAt=now), işaretler null.
- return_pool: taken/*_pending; bekleyen talep cancelled, returned_to_pool, assignee null, sprintId=sonraki.
- cancel: tümü; bekleyen talep cancelled, status cancelled (assignee tarih için kalır).
Tüm bitmemişler karara bağlanınca ana yönetici `closing → closed` (closedAt). Kapanan sprint havuzda değildir; yeni sprint closing sırasında başlatılabilir.
**Zamanlayıcı:** pg-boss YERİNE (plan değişti) şemadaki işaret sütunlarıyla idempotent tarama: `src/server/scheduler.ts` `runScheduledTick(db, now)` → teklif süresi dolumu (30 dk), ticket uyarısı (`dueAt - ticketWarnBeforeHours`, duraklı değilse, warnedAt null), süre dolumu bildirimi (expiredNotifiedAt), talep hatırlatması (`respondBy - managerResponseHours/4`, awaitingRequester değilse, remindedAt null), cevapsız işareti (`overdueAt`; yöneticiye bildirim, ana yönetici paneli öne çıkarır).
